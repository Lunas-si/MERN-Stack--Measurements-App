# MERN-Stack--Lab-Two and Three

This MERN application shows a table of the latest 5 measurements (sensor ID, temperature with one decimal, Unix timestamp).

It auto‑refreshes every minute without reloading the page (AJAX polling).Table headers are clickable to sort the data by unit ID, temperature, or timestamp.Displays the average temperature of the latest 5 measurements, updated automatically when new data arrives.

A manual Refresh button enables fetch the latest data immediately.

The data comes from a database (originally MongoDB, later switched to PostgreSQL for Lab 3 i.e. deployment).
